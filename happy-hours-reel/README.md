# Happy Hours Beauté Reel

A 29.9 s reel for MySalon.ma, delivered in three formats from one project: the 9:16 reel (1080 x 1920), a 4:5 feed
video (1080 x 1350) and a 5-slide 4:5 carousel of stills for a boosted post. sells both Témara offers at once, the OYA MUSE
"Pass L'3chya" and the New Star Beauty "Pass Njma", under one idea everyone already understands: **happy hours**.
Built with Remotion, with its own royalty-free soundtrack and sound effects. Every cut lands on a downbeat.

## Why it works

- **One concept, two salons.** "Happy hours" explains six different time windows in two words; every salon card repeats
  the same grammar: clock, days, hours, rows of old price → new price.
- **The clock.** Each window card has a clock whose gold arc draws the exact window while the hands sweep from the
  opening hour to the closing hour. The viewer sees _when_ without reading.
- **Prices that drop.** Old price struck through in the salon's accent colour, new price counting down and landing with
  a stamp, so the saving is felt, not just read.
- **One ask.** Everything funnels to "Écrivez-nous en DM" on the MySalon.ma account, with the three-step explainer
  right before it so the DM makes sense.

## Run it

```bash
cd happy-hours-reel
npm install
npm run dev           # Remotion Studio at http://localhost:3000
npm run render        # 9:16 reel      -> out/happy-hours-reel.mp4
npm run render:post   # 4:5 feed video -> out/happy-hours-post.mp4
npm run carousel      # 4:5 carousel   -> out/carousel/01..05.jpg
```

## Formats

The scenes read the canvas height and switch to a compact layout below 1600 px (`src/layout.ts`), so the same
compositions render as:

- `HappyHoursReel` – 1080 x 1920, for Reels / TikTok / Stories.
- `HappyHoursPost` – 1080 x 1350, the feed "capsule" video to post and boost.
- `HappyHoursCarousel` – 1080 x 1350 with a "Glissez →" hint on the cover and no music; `npm run carousel` renders
  its five settled frames as JPEG slides: cover, OYA MUSE, New Star Beauty, how to book, call to action.

If Remotion cannot download Chrome Headless Shell in your environment:

```bash
npx remotion render HappyHoursReel out/happy-hours-reel.mp4 --browser-executable=/path/to/chrome
```

## Music and sound effects

`public/music/happy-hours-theme.mp3` is generated by `scripts/make-music.mjs`: an energetic pop / house groove in A minor
at 128.57 BPM (exactly 14 frames per beat at 30 fps), 16 bars: quiet two-bar intro with a snare build, the drop on
salon 1 (bar 3), crashes on every scene change, a lead melody over the second salon and the CTA, a build under the
how-to and a second drop on the CTA (bar 14). `public/sfx/*.wav` come from `scripts/make-sfx.mjs`. Everything is
synthesised from scratch, so it is free to use anywhere.

```bash
npm run music                                   # regenerates public/music/happy-hours-theme.wav
ffmpeg -i public/music/happy-hours-theme.wav -codec:a libmp3lame -b:a 192k public/music/happy-hours-theme.mp3
npm run sfx                                     # regenerates public/sfx/*.wav
```

To post with a trending sound instead, set `musicFile` to `null` in `src/Root.tsx` (or in the Studio props panel),
render, and add the audio in Instagram / TikTok. The cuts are 1.87 s apart (one bar at 128.57 BPM), so pick a track
around 128 BPM if you want them to stay on the beat. The sound effects stay in the file either way.

## Customize

All copy, prices, hours and photos are props on the `HappyHoursReel` composition (Studio props panel or `src/Root.tsx`):

- `site` – the platform name shown on the booking calendar.
- `hook.leftImage / rightImage / line1 / line2 / line3 / subtitle` – the split hook.
- `salons[]` – two salons: `label`, `name` (+ `nameLine2`), `place`, `logo`, `backdrop`, `palette` (`bg`, `bgDeep`,
  `deep`, `accent`, `soft`), one or two `windows` (`title`, `days`, `hours`, `fromHour/toHour` for the clock, up to
  three `rows` with an `image` or a `hair` icon, `name`, `oldPrice`, `newPrice`), and a `note` pill.
- `how.*` – question, answer, the three steps, the sample code, the DM message, the pay/paid labels, the slot, the footer pill.
- `cta.*` – the three title lines, the lead line, the button label, the footer text (`\n` breaks lines).
- `musicFile` – audio file inside `public/`, or `null`.

Scenes are whole bars (56 frames) long; keep that grid if you re-order them so the cuts stay on the beat.
Each scene is also registered under the `HappyHoursReel-Scenes` folder in Studio.
