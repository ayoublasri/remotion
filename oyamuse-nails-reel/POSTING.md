# Posting the OYA MUSE nails reel

## Files

- `out/oyamuse-nails-reel.mp4`: the reel, 28.8 s, no audio.
- `out/oyamuse-nails-reel-silent-track.mp4`: the same with a silent audio track (some upload tools want one).
- `out/cover-after.png`: the « Après » print, for the cover.
- `out/cover-end.png`: the call to action, if you prefer the brand on the grid.

## Sound

The reel is silent by design. Add a trending sound in the Instagram editor
at posting time (soft piano, lo-fi or an Afrobeats instrumental all fit the
pace), or post it as is: the flip at 9.3 s and the pull-out at 20 s read
without sound.

## The call to action

The reel ends on « Lien en bio ». Before posting, make sure the link in the
OYA MUSE bio opens the booking page (MySalon) directly, not a link tree with
several choices. Pin a comment with the same link.
