# Oyamuse Reel

A vertical 9:16 brand reel (1080 x 1920, 30 fps, 29.9 s) for @oyamuse.ma, built with Remotion, with its own royalty-free
soundtrack. Every cut lands on a downbeat of the music, and there is almost no text: one hook, one-word section labels, one invite.

| Bars  | Frames    | Scene   | What happens                                                                                                        |
| ----- | --------- | ------- | ------------------------------------------------------------------------------------------------------------------- |
| 1–2   | 0 – 112   | Hook    | "Regardez vos ongles." then "Puis regardez ça." over the pearl set while the music builds (snare roll, riser).      |
| 3     | 112 – 168 | Logo    | The drop: the OYA logo slams in with a rotating gold ring, the handle below.                                        |
| 4–9   | 168 – 504 | Nails   | Six sets, one bar each: punch-in, shine sweep, twinkles, "NAILS" label and the logo top right.                      |
| 10–11 | 504 – 616 | Brows   | Before/after composite; the "après" half is covered by a cream panel that drops on bar 11.                          |
| 12    | 616 – 672 | Lashes  | Lash-lift close-ups.                                                                                                |
| 13–14 | 672 – 784 | Montage | Eight photos, one beat (14 frames) each, over the snare build.                                                      |
| 15–16 | 784 – 896 | CTA     | Second drop: logo, "Réservez votre moment", "Ongles · Cils · Sourcils", a pulsing "Lien en bio" button, the handle. |

## Run it

```bash
cd oyamuse-reel
npm install
npm run dev      # Remotion Studio at http://localhost:3000
npm run render   # writes out/oyamuse-reel.mp4
```

If Remotion cannot download Chrome Headless Shell in your environment:

```bash
npx remotion render OyamuseReel out/oyamuse-reel.mp4 --browser-executable=/path/to/chrome
```

## Music

`public/music/oyamuse-theme.mp3` is generated by `scripts/make-music.mjs`: an energetic pop / house groove at 128.57 BPM
(exactly 14 frames per beat at 30 fps), 16 bars: four-on-the-floor kick, claps, off-beat open hats, driving octave bass,
plucky chord stabs with sidechain pump, sparkle arpeggios, a lead melody, snare rolls and risers into the two drops
(bar 3 and bar 15). It is synthesised from scratch, so it is free to use anywhere.

```bash
npm run music                                   # regenerates public/music/oyamuse-theme.wav
ffmpeg -i public/music/oyamuse-theme.wav -codec:a libmp3lame -b:a 192k public/music/oyamuse-theme.mp3
```

To use a trending sound instead, set `musicFile` to `null` in `src/Root.tsx` (or in the Studio props panel), render, and add the
audio in Instagram / TikTok. The cuts are 1.87 s apart (one bar at 128.57 BPM), so pick a track around 128 BPM if you want them to
stay on the beat.

## Customize

All copy and photos are props on the `OyamuseReel` composition (Studio props panel or `src/Root.tsx`):

- `handle`, `logo` – the handle and the logo file in `public/images`.
- `hook.line1 / line2` – the two hook lines.
- `labels.nails / brows / lashes` – the one-word section labels.
- `nails[]` – six sets: `image`, `focusX/focusY` (crop focus in %), `sparkles` (twinkle positions in %).
- `brows` – the before/after composite and its two labels; `lashes` – the lash close-up.
- `montage[]` – eight image files, one beat each.
- `cta.title1 / title2 / subtitle / button` – the invite.
- `musicFile` – audio file inside `public/`, or `null`.

Scenes are whole bars (56 frames) long; keep that grid if you re-order them so the cuts stay on the beat.
Each scene is also registered under the `OyamuseReel-Scenes` folder in Studio.

## Notes

- Key text stays inside the Instagram / TikTok safe area (nothing important above y = 150 or below y = 1500).
- Fonts (Cinzel, Playfair Display, Inter) are bundled under the SIL Open Font License in `public/fonts`.
- The project lives outside `packages/` on purpose so the monorepo's Bun workspace does not pick it up; it uses the published
  `remotion@4.0.522` packages and plain `npm`.
