# Oyamuse Reel

A vertical 9:16 brand reel (1080 x 1920, 30 fps, 28.8 s) for @oyamuse.ma, built with Remotion, with its own royalty-free soundtrack.
Every cut lands on a downbeat of the music.

| Bars  | Frames    | Scene    | What happens                                                                                                            |
| ----- | --------- | -------- | ----------------------------------------------------------------------------------------------------------------------- |
| 1–2   | 0 – 144   | Hook     | "Regardez vos ongles. Maintenant." then "Vous voyez ? Il est temps." over the pearl set, with a riser in the music.     |
| 3     | 144 – 216 | Brand    | The drums drop: OYAMUSE wordmark, gold lines, "Nails · Lashes · Brows", handle.                                         |
| 4–6   | 216 – 432 | Nails    | One set per bar (glazed pearl, sirène, bleu royal), shine sweep, twinkles, captions on beat 2.                          |
| 7–9   | 432 – 648 | Brows    | Before/after composite: the "après" half is covered by a cream panel that drops on bar 8, then the lash-lift close-ups. |
| 10    | 648 – 720 | Services | "Tout, au même endroit." with four services landing on eighth notes.                                                    |
| 11–12 | 720 – 864 | CTA      | Wall of the work behind "Réservez votre moment.", the handle, a pulsing "Réservation en DM" button.                     |

## Run it

```bash
cd oyamuse-reel
npm install
npm run dev      # Remotion Studio at http://localhost:3000
npm run render   # writes out/oyamuse-reel.mp4
```

If Remotion cannot download Chrome Headless Shell in your environment:

```bash
npx remotion render OyamuseReel out/oyamuse-reel.mp4 --browser-executable=/path/to/chrome
```

## Music

`public/music/oyamuse-theme.mp3` is generated by `scripts/make-music.mjs`: a warm lo-fi / R&B groove at 100 BPM
(12 bars, keys, sub bass, kick, clap, hats, sparkle bells, a riser into the drop on bar 3 and crashes on bars 3, 7 and 11).
It is synthesised from scratch, so it is free to use anywhere.

```bash
npm run music                                   # regenerates public/music/oyamuse-theme.wav
ffmpeg -i public/music/oyamuse-theme.wav -codec:a libmp3lame -b:a 192k public/music/oyamuse-theme.mp3
```

To use a trending sound instead, set `musicFile` to `null` in `src/Root.tsx` (or in the Studio props panel), render, and add the
audio in Instagram / TikTok. The cuts are 2.4 s apart (one bar at 100 BPM), so pick a track around 100 BPM if you want them to
stay on the beat.

## Customize

All copy is exposed as props on the `OyamuseReel` composition (Studio props panel or `src/Root.tsx`):

- `handle` – shown in the brand scene and the CTA.
- `hook.line1..4` – the four hook lines.
- `brand.name / descriptor` – wordmark and the spaced descriptor.
- `nails[]` – three sets: `image` (file in `public/images`), `title`, `descriptor`, `focusX/focusY` (crop focus in %), `sparkles` (twinkle positions in %).
- `brows.*` – the before/after composite, labels, the cover panel copy and the lash close-up caption.
- `services.title / items / footnote`, `cta.title1 / title2 / button / footer`.
- `musicFile` – audio file inside `public/`, or `null`.

Scenes are one or more whole bars (72 frames) long; keep that grid if you re-order them so the cuts stay on the beat.
Each scene is also registered under the `OyamuseReel-Scenes` folder in Studio.

## Notes

- Key text stays inside the Instagram / TikTok safe area (nothing important above y = 150 or below y = 1500).
- Fonts (Playfair Display, Inter) are bundled under the SIL Open Font License in `public/fonts`.
- The project lives outside `packages/` on purpose so the monorepo's Bun workspace does not pick it up; it uses the published
  `remotion@4.0.522` packages and plain `npm`.
