# Media left out of this copy

This copy of the onetake skill (github.com/berg-1/onetake-motion, commit 36072d3,
a fork of github.com/feitangyuan/onetake) omits the rendered case films and the
README gifs, about 68 MB of binaries that the method does not need:

- `cases/*/<film>.mp4` (the ten case films; their READMEs with beat sheets are kept)
- `assets/hero.gif`, `assets/cases/*.gif`

Clone the upstream repository to see them. Everything else (SKILL.md, references,
lib/motion.js, lib/ui_kit.js, scripts, templates, looks with their fonts, gallery
sheets, LICENSE) is complete.
